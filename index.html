Experiment brief

Understand the concept before running it

A focused experiment aligned with supervised learning and classification evaluation.

🎯
Aim

Study how a Logistic Regression classification threshold changes predictions and the trade-off between precision and recall.

🧪
Objectives

Interpret the confusion matrix; calculate classification metrics; compare thresholds on the validation set; explain false positives and false negatives.

🛠️
Tools & method

Python, scikit-learn, Logistic Regression, StandardScaler and the built-in Breast Cancer Wisconsin benchmark dataset. A stratified 60/20/20 training, validation and final test split is used.

Experiment workflow

Tasks to complete

Follow these steps and record your own observations. The optional viva practice below is for revision, not a compulsory quiz.

1. Record the baseline

Keep the threshold at 0.50. Note the validation TP, TN, FP, FN, accuracy, precision, recall, F1-score, specificity and ROC-AUC.

2. Compare thresholds

Try 0.25, 0.50 and 0.75. Observe how predicted-positive counts, false negatives, false positives and the other metrics change.

5. Save your observation

Export the CSV and write one inference about the precision/recall trade-off plus a conclusion about why the threshold matters.

05 / Learn & check

Concept notes and viva practice

Use these short definitions to explain the experiment. The viva self-check is optional and does not gate the lab.

Decision threshold

Probability cut-off used to convert model scores into class labels. A threshold of 0.50 is common, but not always optimal.

Precision

TP / (TP + FP). Of all cases predicted positive, what fraction were actually positive?

Recall (sensitivity)

TP / (TP + FN). Of all actual positive cases, what fraction did the model detect?

F1-score

2 × (Precision × Recall) / (Precision + Recall). The harmonic mean of precision and recall.

Specificity

TN / (TN + FP). Of all actual negative cases, what fraction were correctly identified?

ROC-AUC

Measures how well the model ranks positive cases above negative cases across thresholds; it does not change just because the decision cut-off changes.

  4. Generate malignant-class probabilities for validation and test subsets.
  5. Change the threshold to produce new validation predictions without retraining the model.

06 / Lab-record summary

Inference and conclusion

Use the live results above when writing the observation section of your lab record.

Inference

Changing the classification threshold changes the number of positive predictions, so precision, recall, specificity and the confusion-matrix counts can change even though the trained model stays the same. ROC-AUC stays constant because the underlying probability rankings remain unchanged.

Conclusion

The experiment demonstrates that 0.50 is not automatically the best threshold for every task. A suitable threshold depends on the relative cost of false negatives and false positives and should be selected using validation data, then assessed on held-out test data.

What to report

Record the selected threshold, TP, TN, FP, FN, accuracy, precision, recall, F1-score, specificity and ROC-AUC. Explain at least one trade-off you observed. Export the current run as CSV for further analysis.
